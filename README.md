# 安装路径提醒

面向 Windows 10 22H2 的中文桌面托盘工具。在检测到疑似安装程序时提醒用户检查安装位置，并生成“默认根目录 + 软件名称”的建议路径。

例如，根目录为 `D:\Apps`、软件为 Firefox 时，建议路径为 `D:\Apps\Firefox`。

## 原生通知没有横幅时

v1.2.1 会检查通知允许状态，显示测试反馈并保存异步错误。发送成功不代表横幅出现；请查看通知中心及系统的勿扰、全屏和应用横幅设置。详见 [通知排查说明](docs/通知排查说明.md)。

## 下载与使用

**[下载 v1.2.1 软件包](downloads/InstallPathReminder-v1.2.1.zip?raw=1)** · [SHA-256 校验值](downloads/SHA256SUMS.txt)

1. 下载并解压整个文件夹，双击 `InstallPathReminder.exe`。
2. 设置“建议安装根目录”，选择“弹窗提醒”或“Windows 原生通知”，保存设置。
3. 点击“测试提醒”检查效果，然后收起到托盘，保持工具运行。
4. 启动安装程序，点击提醒中的“一键复制建议安装路径”，在安装向导的目标路径框按 `Ctrl+V` 粘贴。

请保留程序同目录的 `.config` 和 `Microsoft.Toolkit.Uwp.Notifications.dll`。升级前退出旧版本；启用了自启动的用户请在新版本重新保存设置。

## 功能

- 弹窗和 Windows 原生 Toast 通知可选，均提供“一键复制建议安装路径”按钮。
- 根据产品名称、文件描述或安装包文件名推断软件名称；可读取本地 MSI 的 ProductName。
- 为每款软件建议单独子文件夹，清理非法字符、设备保留名和过长名称。
- 弹窗路径可以编辑后再复制。未知名称标为“待确认软件-编号”，便于核对。
- 每条通知绑定当时的完整路径，修改根目录或重启后，旧通知仍使用原路径。
- 托盘运行、暂停提醒、忽略列表、最近 200 条记录和可选登录自启动。

工具只提供提醒和复制，不自动创建安装目录、不暂停安装，也不自动修改安装向导。安装识别和软件名推断可能误报或漏报；部分安装器不允许选择目录。

## 系统要求和验证

- 目标系统：Windows 10 22H2，.NET Framework 4.8，AnyCPU。
- 运行无需 Python、.NET SDK 或联网下载依赖。
- 已通过 **149 项相关自动化检查（本次；另有 8 项进程监测基线检查）**，覆盖检测、存储、路径生成、通知动作、复制路由和进程监测。
- 实际验证主机为 Windows 11 25H2；尚未在真实 Windows 10 22H2 设备上验收。
- 原生 Toast 已成功提交给 Windows；真实通知按钮点击和通知冷启动尚未完成端到端验收。程序未进行商业代码签名。

## 构建与测试

源码在 `source`。Windows 上双击 `source\build.cmd`，或在允许脚本执行的 PowerShell 中运行：

```powershell
cd source
.\build.ps1
.\test.ps1
```

构建使用 Windows 自带的 .NET Framework C# 编译器，不需要下载依赖，输出位于 `source\build`。构建前请退出从该目录运行的程序。

测试前请退出提醒工具，以免无害测试进程触发安装提醒。常规测试使用替代的系统通知和剪贴板接口，不修改真实自启动项；进程测试只启动等待后退出的无害程序。需要跳过进程监测测试时，运行 `.\test.ps1 -SkipProcessTests`。请遵循所在设备的脚本执行策略。

## 本地数据与移除

设置和记录保存在 `%LOCALAPPDATA%\InstallPathReminder`。仓库不包含运行时设置、个人记录或测试数据。

移除时先取消登录自启动并保存，再从托盘选择“清除原生通知并退出”，最后删除程序文件夹。请在移动或删除程序前清理它的通知注册，详见使用说明。
