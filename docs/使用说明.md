# 安装路径提醒 v1.2.1

这是一个中文 Windows 托盘工具。识别到疑似安装程序时，按“你设置的根目录 + 软件名称”生成建议路径，并通过弹窗或 Windows 原生通知提醒。两种方式都提供 **“一键复制建议安装路径”** 按钮，将完整路径写入剪贴板，供你粘贴到安装向导。

例如：根目录为 `D:\Apps`，识别的软件为 `Firefox`，建议路径就是 `D:\Apps\Firefox`。建议路径只在点击复制按钮后写入剪贴板；程序不会自动创建文件夹，也不会自动修改安装向导中的路径。

## 快速使用

1. 将整个软件文件夹解压到固定位置，双击 `InstallPathReminder.exe`。请保留同目录的 `.config` 和 `Microsoft.Toolkit.Uwp.Notifications.dll`，不要只移动 EXE。
2. 在“常用设置”填写“建议安装根目录”，例如 `D:\Apps`，或点击“选择目录…”。只填写统一的存放目录，软件名称会自动追加。
3. 在“提醒方式”选择“弹窗提醒”或“Windows 原生通知”，点击“保存设置”。“测试提醒”会预览界面上当前的目录和方式，不启动真实安装，也不保存尚未保存的设置。
4. 点击“收起到托盘”，或关闭主窗口，保持工具运行；然后启动安装包。
5. 在提醒中点击“一键复制建议安装路径”，返回安装向导，在“自定义 / 高级 / 浏览”中的目标路径框按 `Ctrl+V` 粘贴，再确认安装。

升级时先退出旧版本，再运行新版本。已有配置和历史记录会继续读取；若启用了登录自启动，请在新版本中重新保存设置，使启动项指向新文件夹。

首次运行默认使用弹窗，启用提醒和弹窗提示音，关闭登录自启动。初始根目录优先选用第一个可用、剩余空间超过 1 GB 的非系统固定磁盘下的 `Apps` 文件夹；没有符合条件的磁盘时通常使用 `C:\Apps`。这个初始值不代表已检查目标软件所需空间。

根目录必须是已连接的本地固定磁盘中的文件夹，可以尚未创建。不能使用磁盘根目录、网络路径、无效目录名称或 Windows 系统目录。

## 软件名称和独立文件夹

- EXE 优先读取产品名称，其次读取文件描述，最后从安装包文件名推断。会清理常见的 Setup、Installer、安装程序、架构和部分版本后缀。
- 对能读取路径的本地 MSI 包，只读查询其 `ProductName` 属性；读取失败时尝试安装包文件名。此操作不运行 MSI 安装动作。
- 文件夹名称会清理 Windows 不允许的字符、设备保留名称及过长内容，完整建议路径最多 240 个字符。
- 如果只有 `setup.exe` 之类的通用名称，会生成 `待确认软件-随机编号`，避免多个未知安装器共用一个 Setup 文件夹。名称是推断结果，请在安装前核对。
- 弹窗中的完整路径可以直接编辑后复制。原生通知正文可打开对应详情，在详情中调整；原生通知按钮始终复制通知生成时保存的路径。
- 同一软件可重复建议同名目录。是否已有安装、剩余空间是否足够及软件实际要求，仍需在安装向导中确认。

## 两种提醒方式

**弹窗提醒**显示建议路径、可编辑文本框和“一键复制建议安装路径”按钮。复制成功后按钮变为“已复制到剪贴板”；剪贴板忙或输入路径无效时会提示失败。“知道了”关闭提醒，弹窗提示音由本程序设置控制。

**Windows 原生通知**使用 Windows Toast，包含完整建议路径及“一键复制建议安装路径”操作按钮。点击按钮直接复制该条提醒的完整路径；点击通知正文打开对应详情。外观、横幅显示时长和声音由 Windows 控制，本程序不另播提示音。

每条原生通知使用独立编号，绑定当时保存的完整建议路径。之后更改根目录、收到其他提醒或重启程序，不会把旧通知的复制目标换成最新路径。退出后点击通知时，Windows 可以启动原位置的程序处理操作。请保持整个软件文件夹路径不变；移动、删除程序或清除通知注册后，旧通知可能无法启动程序。

原生通知受 Windows 通知开关、专注助手 / 勿扰模式及组策略影响，系统可能不显示横幅。请通过“提醒记录”查看记录；“已提交系统通知”表示系统接口调用成功，不代表用户已经看到。发送发生可捕获错误时会记录失败，不自动切换到弹窗。历史只保留最近 200 条；已被清理或挤出的通知记录会提示过期，不会复制其他软件的路径。

通知集成使用随包提供的 [Microsoft.Toolkit.Uwp.Notifications 7.1.3](https://www.nuget.org/packages/Microsoft.Toolkit.Uwp.Notifications/7.1.3)。程序启动时注册当前用户下的通知激活处理器，以接收旧通知点击；这与“登录 Windows 后自动启动”设置是独立功能。组件许可见 `THIRD-PARTY-NOTICES.md` 及所附 MIT 许可证。

## 托盘、自启动和忽略列表

- 双击右下角托盘图标打开设置；图标可能在任务栏的隐藏图标区域。
- 右键托盘图标可查看提醒记录、测试提醒、暂停或恢复、退出。托盘测试使用已保存设置。关闭主窗口只是收起到托盘；使用“退出程序”才会结束监测。
- 如需登录后运行，勾选“登录 Windows 后自动启动”并保存，只写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 启动项。移动前先取消自启动并保存，移动后可重新启用。
- 可在提醒窗口点击“不再提醒这个安装程序”，按完整可执行文件路径忽略；在“忽略列表”恢复。无法读取完整路径时该按钮不可用。MSI 共用系统安装服务，因此不提供按 msiexec 忽略。

## 识别范围和限制

工具根据 EXE 名称、文件描述、产品名称和部分命令行，以及 `msiexec` 的 `/i`、`/package`、`/a` 参数启发式识别安装。它过滤可识别的卸载、更新和修复行为，减少短时间内同一安装器及其子进程的重复提醒。只监测当前登录会话中新启动的程序，请先运行工具，再打开安装包。

程序不会暂停或阻止安装，提醒出现时安装可能已继续。部分安装器本身不允许选择目录，本工具无法增加这个能力。Microsoft Store、winget、静默安装、没有明显安装特征的程序，以及无法读取信息的受保护进程，都可能漏报，也可能发生误报。

UAC 安全桌面上的提醒不可见，需要回到普通桌面。监测优先使用进程启动事件，不可用时回退到约一秒一次的轮询，可能遗漏短暂进程。请确认主窗口显示监测已就绪。

## 本地数据与移除

程序无需网络连接，不要求管理员权限。设置和最近 200 条记录保存在：

```text
%LOCALAPPDATA%\InstallPathReminder
```

- `settings.xml`：根目录、提醒方式、提醒和弹窗声音开关、忽略列表。
- `history.xml`：时间、可读取到的安装器名称和路径、软件名称、当时的根目录及完整建议路径、通知编号、识别依据和状态。
- 损坏的 XML 会尝试保留 `.corrupt-` 备份，再使用默认设置或空记录。

旧版记录若没有完整建议路径，打开详情时按旧根目录或当前配置及旧安装器信息生成子文件夹；新记录则保存固定的路径快照。

移除时先取消登录自启动并保存，再从托盘菜单选择“清除原生通知并退出”，最后删除整个软件文件夹。也可先正常退出，再从该版本的原 EXE 运行 `InstallPathReminder.exe --unregister-notifications` 清除它自己的通知及相关注册。通知清理只针对该程序，须在移动或删除文件夹前执行。清理本身不删除设置和历史文件，若不需要可在退出后手动删除上述数据目录。

## 系统要求、源码与验证

目标平台为 Windows 10 22H2、.NET Framework 4.8、Windows Forms，支持 32 / 64 位 Windows。运行成品无需 Python、.NET SDK 或联网下载依赖。Windows 10 22H2 的框架版本见 [Microsoft 版本与依赖说明](https://learn.microsoft.com/en-us/dotnet/framework/install/versions-and-dependencies)。

实际验证主机为 Windows 11 25H2、内部版本 26200、.NET Framework 4.8.1，尚未在真实 Windows 10 22H2 设备上验收。自动化与原生通知实测范围详见 `验证说明.md`。发布包未做商业代码签名。

`source` 包含源码、已固定版本的通知 DLL、许可证和测试。双击 `source\build.cmd` 构建；或在允许脚本执行的 PowerShell 中运行：

```powershell
.\build.ps1
.\test.ps1
```

构建调用 Windows 自带的 .NET Framework C# 编译器，在 `build` 目录输出程序，无需下载依赖。测试验证安装识别、存储、名称与路径生成、通知按钮和路由、实际进程监测；测试进程只等待后退出，不安装软件。常规测试使用替代的系统通知和剪贴板接口，不修改真实启动项。测试前退出提醒工具，避免测试进程触发提醒；可用 `test.ps1 -SkipProcessTests` 跳过进程监测测试。系统策略禁止脚本时，请遵循设备策略，运行成品 EXE 不需要执行脚本。
