建议在目标 Windows 10 22H2 设备上完成以下验收：

1. 设置根目录，分别预览弹窗与原生通知，检查显示为“根目录\示例软件”。
2. 点击两种提醒中的复制按钮，粘贴到一个空白文本框，核对完整路径；在弹窗中编辑路径后再复制。
3. 保留旧通知，改变根目录并生成新通知，分别点击复制，核对各自路径。
4. 正常退出工具后点击仍保留的通知按钮，核对程序恢复及剪贴板内容。
5. 启动一个可以取消的安装向导，核对提醒与软件名称，取消安装。
