# v1.2.1 通知排查更新

修复测试原生通知时缺少反馈的问题：发送前检查 Windows 是否禁用通知；测试后显示提交结果和当前系统提示状态；接收异步发送失败，并将错误详情保存到提醒记录（鼠标悬停记录可查看）。窗口标题显示版本号。

本机复测得到 Setting=Enabled，通知历史中有测试通知，Shell state=2（QUNS_BUSY）。这表明发送已经进入系统通知历史，而系统报告忙碌/全屏/演示状态，横幅可能被抑制；不能仅由该状态断言勿扰开关开启。请先退出全屏或演示模式，在 Windows 11 按 Win+N 查看通知中心，再检查“设置 → 系统 → 通知”中的勿扰及本应用横幅设置。程序不会强制修改这些系统设置。

已退出残留内部测试程序 ReminderUiTest.exe，并用发布版复测。请使用发布文件夹中的 InstallPathReminder.exe。残留测试程序不在发布包内。

本次149项自动化检查通过（未重复运行未修改的8项进程监测检查）；新增覆盖忙碌状态提示、允许状态不承诺横幅、未知状态指导、同步错误详情持久化、异步错误准确匹配记录。真实系统探针等待10秒，未收到异步错误，通知历史计数为1。尚未确认真实横幅显示及按钮点击；Windows 10 22H2实机验证仍待完成。

编译源码新增 compiler-references.ps1 和 lib/WinRT 的官方 Windows SDK 编译元数据，许可证及来源在该目录。这些文件仅编译使用；运行成品无需额外 SDK。
